# 01 电影 规范

> 先遵守《00_通用规则》，本文件为电影类的专属规则。

## 0 类别定位与默认值
- 叙事长片，一个完整的、有深度的故事，观众为完整观影而来。
- **默认时长**：用户未指定 → 100 分钟。常见区间 80–150 分钟。
- **默认画幅**：横屏 2.39:1 / 16:9（可由用户指定）。
- 核心追求：**人物弧光 + 主题 + 视听记忆点**。

## 一、故事大纲规则

### 1.1 结构：三幕八序列（按总时长比例分配时间预算）
| 段落 | 占比 | 内容要求 |
|---|---|---|
| 第一幕·铺陈 | 约 25% | 常态世界 → 激励事件（约 10–12%处）→ 主角拒绝/犹豫 → **第一幕转折**（主角被迫进入新世界） |
| 第二幕上·对抗 | 约 25% | 新世界规则、盟友与敌人、"乐趣与游戏"（类型承诺兑现）→ **中点**（真相/局势反转，赌注升级） |
| 第二幕下·恶化 | 约 25% | 压力加码、盟友背叛/失去 → **全盘皆输（低谷）** |
| 第三幕·决战与结局 | 约 25% | 主角完成内在转变 → 高潮对决 → 结局 → 终场画面（回扣开场） |

以 100 分钟为例：激励事件≈第 10–12 分钟；第一幕转折≈25 分钟；中点≈50 分钟；低谷≈75 分钟；高潮≈85–95 分钟。**其他时长按比例换算并写入大纲。**

### 1.2 大纲必备要素（在通用骨架之上追加）
1. **主角的"外在目标"与"内在需求"**：二者必须有张力（想要的 ≠ 需要的）。
2. **人物弧光**：主角在开场的信念/谎言 → 结尾的转变，用一句话写清。
3. **对手/对立力量**：必须有立体动机，不是"为坏而坏"。
4. **关键节拍表**：激励事件、第一幕转折、中点、低谷、高潮、结局，各 2–4 行。
5. **8 个序列梗概**：每个序列 3–6 行，写清"目标—阻碍—结果—新的问题"。
6. **伏笔与回收表**：至少 3 组（道具/台词/场景）。
7. **视觉母题**：1–3 个反复出现的画面/道具/色彩，并说明其象征。
8. **类型承诺**：该类型观众期待看到的 3 个"必看场面"（如悬疑的反转、喜剧的名场面）。

### 1.3 创意方向
- 追求"**熟悉类型 + 陌生切口**"：类型清晰，但切入角度、人物身份或叙事视角要新。
- 可考虑的升华手法：时间结构玩法（倒叙/多线/循环）、视角限制（只跟随一人/一个空间）、单一规则设定（"若……则……"的高概念）、反类型人物（让不该出现在这个类型的人当主角）。
- 主题要**落在行动上**：最后的选择必须用行动证明主题，而不是用台词宣布。

### 1.4 禁忌
- 第二幕"流水账"：中间 50% 必须有中点与低谷两次方向性改变。
- 最后一刻靠外力/巧合解围（机械降神）。
- 结尾主角与开头完全一样，没有任何变化。

## 二、剧本规则

### 2.1 格式
- 标准电影剧本格式：场景标题 / 动作 / 角色名 / 对白 / 括号提示。
- **体量**：1 分钟 ≈ 1 页 ≈ 300–400 字。100 分钟 ≈ 3–4 万字（≈100 页）。
- **场景数**：约每 2–3 分钟一个场景，100 分钟约 35–55 个场景。

### 2.2 分段交付（避免一次生成走样）
- 默认**按序列分批**生成（序列 1→8），每批开头附"前情摘要 + 人物状态表 + 伏笔登记表"，保证连贯。
- 每批结束输出：已用时长/字数 与 剩余时长的预算对比。

### 2.3 写作要求
1. 前 10 页（≈10 分钟）必须完成：世界、主角、缺陷、激励事件。
2. 每个序列结尾必须留"推进力"（悬念/决定/新问题）。
3. 对白：每个角色至少有 2 个**可辨识的语言特征**（节奏、用词、口头禅、回避的话题）。
4. 高潮必须是**主角在内在转变后的选择**，且与开场的"谎言/缺陷"形成对照。
5. 伏笔表里的每一条都要在剧本中出现并回收，并在时长校验表中标注位置。
6. 终场画面必须回扣开场画面。

### 2.4 交付前检查
- [ ] 总页数/字数与时长匹配（±10%）
- [ ] 激励事件/第一幕转折/中点/低谷/高潮的位置与大纲一致
- [ ] 伏笔全部回收
- [ ] 主角弧光完整可见
