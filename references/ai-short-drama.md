# 04 AI短剧 规范

> 先遵守《00_通用规则》，本文件为 AI 短剧类的专属规则。
> 与后续「AI 分镜生成规范」衔接：剧本里的每一个镜头单位，都必须是 **AI 视频模型能稳定生成**的。

## 0 类别定位与默认值
- 竖屏、超短单集、集集强钩、情绪直给的连续短剧，用 AI 生成画面/视频完成。
- **默认体量**：用户未指定 → 30 集 × 1 分钟。常见 20–100 集，单集 0.5–3 分钟。
- **默认画幅**：9:16 竖屏。
- 核心追求：**3 秒钩子 + 每集一个爽点/反转 + 集尾卡点 + AI 可实现**。

## 一、故事大纲规则

### 1.1 全剧结构（按总集数 N 分配）
| 段落 | 集数占比 | 任务 |
|---|---|---|
| 开篇 | 第 1–3 集 | 第 1 集就把**强冲突 + 主角处境 + 反差**拍出来；第 3 集前必须出现第一个"爽点/反转" |
| 升级 | ~10%–60% | 每 3–5 集一个小副本（一个小目标 + 小高潮）；主线推进 |
| **付费卡点 / 大转折** | 约 30%、60% 处（可按平台调整） | 最强悬念/反转，留在这集结尾 |
| 终局 | 最后 ~15% | 终极对决 + 反转 + 情感/爽感收束 |

### 1.2 大纲必备要素
1. **一句话爽点**：这部剧的核心爽感（逆袭/复仇/甜宠/身份反转/悬疑揭秘/治愈）。
2. **强反差人设**：每个主要角色一句话标签 + 一个反差（≤ 5 个主要角色，推荐 3–4 个）。
3. **角色定妆卡**（AI 一致性必需）：每个主要角色固定：年龄、脸型/发型/发色、体型、**标志性服装/配饰（≥ 2 个可辨识特征）**、气质。此卡写入大纲，剧本和分镜不得更改。
4. **场景清单**：全剧核心场景 ≤ 8 个（重复使用，节约一致性成本），每个场景写明视觉关键词（光线/色调/标志物）。
5. **分集大纲**：每集必写：
   ```
   第X集｜标题｜时长 XX 秒
   - 开场钩子（前 3 秒画面/台词）：
   - 本集事件（1 个主事件）：
   - 爽点/反转（1 个）：
   - 集尾卡点：（悬念/反转/抉择，必须让观众点下一集）
   - 出场角色（≤ 3）／场景（1–2 个）
   ```
6. **爽点分布表**：全剧爽点类型与集数，避免连续重复。
7. **伏笔表**：跨集伏笔，标注埋/收的集数。

### 1.3 AI 可实现性约束（写大纲时就要遵守）
- 每集**出场角色 ≤ 3 人**；避免 4 人以上同框的多人互动。
- 每集**场景 ≤ 2 个**；避免频繁换景。
- 避免：复杂肢体接触（拥抱以外的精细动作）、大规模群戏/战争/追车、手部精细操作（写字/打字/弹琴特写）、屏幕/书页上的大段文字、快速武打。
- 情绪**靠表情特写、对视、道具、光影、音乐、台词**来撑，而不是靠复杂动作。
- 必要的"大场面"用**暗示手法**（影子、反应镜头、声音、结果画面）而不是直接生成。

### 1.4 创意方向
- 套路可以用，但要**在套路里加一个新鲜的钩子**（例：复仇+角色身份是 AI/时间循环/反向打脸）。
- 台词要有"可截图的金句"，每集 1 句。
- 情绪曲线：每集内"压抑→爆发"或"误会→揭晓"，节奏明确。

### 1.5 禁忌
- 一集内塞 2 个以上主事件（时间不够，AI 也画不完）。
- 角色过多、关系图复杂（观众与 AI 都会混乱）。
- 连续 3 集的钩子/反转模式雷同。

## 二、剧本规则

### 2.1 单集格式（按"秒"为单位写）
```
第X集｜标题｜目标时长 60 秒
角色在场：…… ｜ 场景：……
[0–3s]   钩子：画面 / 台词
[3–15s]  …
[15–45s] …（主事件 + 爽点/反转）
[45–60s] 集尾卡点
```
- 每个时间块**必须标注秒数**，总和 = 单集时长（±3 秒）。
- 每个时间块 = 1–2 个镜头单位，单个镜头时长建议 **3–8 秒**（符合 AI 视频单段生成习惯）。

### 2.2 体量（以 1 分钟为例）
- 总字数约 **250–350 字**；其中对白 **≤ 120 字**（约 30–35 秒语音，其余留给画面与音乐）。
- 镜头单位约 **8–14 个**。
- 30 秒集：字数 120–180；2–3 分钟集：按比例放大，但**每 60 秒要有一个小转折**。

### 2.3 写作要求
1. **前 3 秒**必须有视觉或台词钩子（强冲突画面/一句狠话/反常识）。
2. **每集只有 1 个主事件 + 1 个爽点/反转 + 1 个集尾卡点**。
3. 对白**短句、口语、情绪直给**，单句 ≤ 20 字为宜；避免大段独白。
4. 角色一律使用**定妆卡**里的固定描述；剧本中角色名后面首次出现附"外观关键词"，后续沿用。
5. 动作描写写成**AI 能执行的单一动作**（"她缓缓抬头，目光转冷"，而非"她一边说话一边整理文件并走向门口"）。
6. 每个镜头单位标注：景别倾向（特写/中景/全景）、情绪、光线/色调关键词、音乐/音效点。方便后续生成分镜。
7. **集尾卡点**必须在最后 3–5 秒出现，并与下一集开场**衔接**（下一集前 3 秒回应上一集卡点，或颠覆观众预期）。
8. 跨集一致性：每集头部附"人物状态/服装/场景状态"，防止出现服装与场景漂移。

### 2.4 交付与校验
- 全剧交付按"集"逐个或分批；每批附**时长校验表**：`集号 | 目标时长 | 各时间块秒数合计 | 总字数 | 对白字数 | 出场角色数 | 场景数`。
- 若总集数 = 60，则剧本必须是 60 集、每集 60 秒；**不得合并、缺失或改变单集时长**。

### 2.5 交付前检查
- [ ] 每集：3 秒钩子 / 1 个爽点 / 集尾卡点
- [ ] 角色 ≤ 3、场景 ≤ 2（超出需回到大纲确认）
- [ ] 秒数合计 = 目标时长（±3 秒）
- [ ] 对白字数不超限
- [ ] 无 AI 难以生成的动作/文字特写
