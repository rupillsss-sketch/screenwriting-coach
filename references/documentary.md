# 07 纪录片 规范

> 先遵守《00_通用规则》，本文件为纪录片类的专属规则。
> **与其他类别最大的区别：真实性优先。** 纪录片的"创意"体现在选题角度、叙事结构与影像表达上，**不是编造事实**。

## 0 类别定位与默认值
- 以真实的人、事、物为对象，通过叙事与影像呈现观点与情感。
- **默认体量**：用户未指定 → 单集 10 分钟。常见 3–60 分钟；系列片 3–12 集。
- **默认画幅**：16:9 横屏。
- 核心追求：**有力的选题角度 + 清晰的叙事线 + 真实可信 + 有余味的表达**。

## 一、故事大纲规则

### 1.1 真实性原则（硬规则）
1. **不编造事实、人物、数据、引语、历史细节。** 用户只给想法而无素材时，大纲只能是"**拍摄/制作方案**"：规划要拍什么、访谁、查什么，所有具体事实标注 **【待核实】**。
2. 所有"预设的采访内容/可能的发现"必须标注 **【预设，待拍摄验证】**。
3. 涉及真实人物/机构，不得做诽谤性或未经证实的指控。
4. 如使用情景再现/AI 生成画面，必须标注为 **【再现/示意】**，并建议在成片中加注。

### 1.2 大纲必备要素
```
【基本信息】片名（暂定）｜时长/集数×单集时长｜题材｜画幅
【选题角度】一句话：为什么是这个题材？为什么是现在？你的独特切入点是什么
【核心命题】这部片子想让观众思考/理解什么
【叙事类型】人物型 / 事件型 / 主题型 / 观察型 / 历史调查型 / 诗电影型（选 1 为主）
【叙事视角与声音】第一人称/第三人称解说/无解说（纯观察）/访谈驱动
【结构设计】按时间预算分章节（见下）
【核心人物/拍摄对象】身份｜与主题的关系｜预设采访方向
【素材与拍摄计划】需拍摄场景｜需档案资料｜需采访对象｜需再现镜头
【影像风格】色彩/镜头语言/音乐气质/节奏
【风险与伦理】隐私、授权、敏感点
```

### 1.3 结构模板（按总时长缩放）
| 结构 | 适用 | 骨架 |
|---|---|---|
| 人物型 | 人物纪录片 | 开场（人物的一个动作/场景）→ 他是谁 → 他的困境/追求 → 转折/代价 → 现状与未来 |
| 事件型 | 事件/调查 | 引子（疑问）→ 背景 → 调查推进 → 关键发现 → 反思 |
| 主题型 | 文化/自然/社会议题 | 引子 → 3–5 个主题章节（并列或递进）→ 总结升华 |
| 观察型 | 跟拍 | 以时间/事件节点串联，少解说，多现场 |

- 10 分钟片：引子 1 分钟 + 3 个章节（各约 2.5–3 分钟）+ 收束 1 分钟。
- 系列片：每集**独立成章**，同时有贯穿全系列的"问题"；第 1 集建立问题，末集回应。

### 1.4 创意方向
- **找到"小切口"**：写"一座城市"不如写"凌晨四点这座城市里醒着的人"。
- **用具体的人和物承载宏大主题**。
- 用**结构**制造张力：悬念设置（先抛疑问）、对比（两个人/两个时代）、递进（越来越深的真相）。
- 避免"介绍式"开场，用一个**有画面感的具体瞬间**开头。

### 1.5 禁忌
- 编造数据/事件/引语。
- 解说词堆砌形容词和口号，替代画面。
- 摆拍痕迹明显且未标注。

## 二、剧本规则（纪录片脚本/文案）

### 2.1 格式：双栏脚本
```
段落｜时间码（预估）｜画面/拍摄内容｜解说词 / 同期声（采访）｜音乐音效｜资料来源/备注
```
- 总时长与大纲一致（±10%）。
- **解说词**语速 3–3.5 字/秒；10 分钟片全解说型约 1500–2000 字；有大量同期声/无解说段落则相应减少。
- 每个段落标注**画面类型**：现场实拍 / 采访 / 档案资料 / 空镜 / 再现（示意）/ 动画图表。

### 2.2 写作要求
1. **画面先行**：先想"观众看到什么"，再写解说；解说只补充画面看不到的信息，不复述画面。
2. **采访部分**：只写**采访提纲与预期方向**，具体答案留空或标注【预设，待采访】；不得替受访者"编"台词。
3. **所有事实性陈述**（时间、数字、人名、因果）必须带 **【来源：待补充/用户提供】** 标签；不确定的标注 **【待核实】**。
4. 开场前 30 秒要有钩子（疑问/强画面/反常识事实）。
5. 解说风格统一：客观克制 / 抒情诗意 / 调查冷静等，在大纲里确定后全片保持。
6. 结尾不总结口号，用一个**有余味的画面 + 一个开放性的问题/细节**收束。

### 2.3 交付前检查
- [ ] 无编造事实；所有事实有来源标签或【待核实】
- [ ] 采访内容均标注为预设
- [ ] 再现/AI 画面已标注
- [ ] 时长、字数匹配，附校验表
