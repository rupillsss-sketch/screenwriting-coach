# 06 微电影 规范

> 先遵守《00_通用规则》，本文件为微电影类的专属规则。

## 0 类别定位与默认值
- 时长短、体量小、**完整的小故事 + 一个强烈的情感/思想落点**。像"一首短诗"，而不是"缩水的电影"。
- **默认时长**：用户未指定 → 10 分钟。常见 3–30 分钟。
- **默认画幅**：16:9 横屏。
- 变体：**品牌微电影**（需要自然植入品牌理念）、**公益微电影**、**参赛/毕设短片**。如属变体，用户需说明；品牌类额外遵守《05_广告》的合规与露出原则（露出更含蓄）。
- 核心追求：**单一事件、单一情感、一个让人回味的瞬间（反转或余味）**。

## 一、故事大纲规则

### 1.1 结构（按总时长分配）
| 段落 | 占比 | 任务 |
|---|---|---|
| 开场/建立 | ~15% | 一个具体的人 + 一个具体的处境，**第一个镜头就要有"问题"** |
| 事件/冲突 | ~45% | 唯一的核心事件，逐步施压 |
| 转折/高潮 | ~25% | 一个反转或情感爆发（核心记忆点） |
| 余韵/落点 | ~15% | 画面收束，留出情绪回味；回扣开场 |

### 1.2 大纲必备要素
1. **一个核心事件**：全片只围绕一件事展开（时间、地点、人物尽量集中）。
2. **一个情感核心**：用一句话写出（如：*"我们总在失去后才学会说出口"*）。
3. **人物 ≤ 3–4 个主要角色**；场景 ≤ 时长（分钟）÷ 2 个（10 分钟 ≤ 5 个场景），时间跨度尽量压缩。
4. **转折设计**：明确"观众以为是 A，其实是 B"的位置与铺垫。
5. **意象/道具**：1–2 个贯穿全片的物件或画面，承载情感并在结尾回响。
6. **叙事视角与影像风格**：谁的视角？写实/诗意/超现实？（写成关键词）。

### 1.3 创意方向
- **以小见大**：用一个极小的细节（一碗面、一部旧手机）撬动一个大的情感。
- **克制**：越短的片子越要"少说"，用画面和留白说话。
- 好的微电影结尾通常是"**一个动作/一个画面**"，而不是"一句总结"。

### 1.4 禁忌
- 多线并行、人物众多、世界观太大（时间装不下）。
- 结尾用旁白/字幕直接说教。
- 为了反转而反转，缺乏情感铺垫。

## 二、剧本规则

### 2.1 格式
- 标准电影剧本格式（场景标题/动作/对白）。
- **体量**：1 分钟 ≈ 250–380 字（微电影偏重画面，对白少于剧集）；10 分钟 ≈ 2500–3800 字；场景约 每 2 分钟 1 个。
- 总时长与大纲一致（±10%）。

### 2.2 写作要求
1. **前 30 秒**（或前 5%）建立人物+问题；**不得用旁白交代背景**，用画面和细节交代。
2. **对白精简**：能删就删；允许大段无对白的段落，用动作/表情/音乐推进。
3. 转折前必须有**至少 2 处伏笔**，转折后要能让观众"回头看"时恍然大悟。
4. 道具/意象在 开头—中段—结尾 **至少出现 3 次**，每次含义递进。
5. 结尾画面回扣开头，形成情绪闭环；片尾字幕/音乐点明余味但不说教。
6. 标注关键的声音设计（环境音/静默/音乐切入点）——微电影靠声音塑造情绪。

### 2.3 交付前检查
- [ ] 只有一个核心事件，场景数不超限
- [ ] 转折有铺垫，结尾有回响
- [ ] 总时长（字数）匹配
- [ ] 附时长校验表
