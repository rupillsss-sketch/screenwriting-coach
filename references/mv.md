# 08 MV 规范

> 先遵守《00_通用规则》，本文件为 MV（音乐视频）的专属规则。
> MV 的"时间"由**歌曲**决定，不是由剧情决定：先有音乐结构，后有画面叙事。

## 0 类别定位与默认值
- 为一首歌创作的视觉表达，**画面是音乐的情绪放大器**，而不是歌词的逐字翻译。
- **默认时长**：用户未指定 → 与歌曲实际时长一致；无歌曲时默认 3 分 30 秒。常见 2–5 分钟。
- **默认画幅**：16:9 横屏（用户指定竖屏时调整）。
- 核心追求：**视觉概念统一 + 与音乐节奏/情绪同步 + 一个令人记住的画面意象**。

## 一、故事大纲规则

### 1.1 先拿到"音乐信息"（缺失则追问，最多 3 个问题）
1. **歌词**（或歌曲主题/情绪）
2. **时长与段落结构**（前奏/主歌/预副歌/副歌/间奏/桥段/尾奏及各自时间）
3. **曲风与 BPM、情绪**
- 无歌词/段落信息时：按"歌曲标准结构"假设并声明，例：前奏 0:00–0:15 / 主歌A 0:15–0:50 / 预副歌 0:50–1:05 / 副歌 1:05–1:40 / 间奏 1:40–1:55 / 主歌B 1:55–2:25 / 副歌 2:25–3:00 / 桥段 3:00–3:15 / 尾声 3:15–3:30。
- **不得擅自修改、改写或虚构歌词**；不得照搬具体在世歌曲的歌词作为"示例"。

### 1.2 MV 叙事类型（选定一种为主）
| 类型 | 特点 | 适合 |
|---|---|---|
| 叙事型 | 有完整的小故事，歌词与剧情呼应 | 情感/抒情类 |
| 表演型 | 歌手/乐队演出为主，靠场景与调度出彩 | 摇滚/流行/说唱 |
| 概念型 | 以意象/抽象/隐喻表达情绪，无明确剧情 | 电子/民谣/实验 |
| 混合型 | 叙事 + 表演交织 | 主流制作 |

### 1.3 大纲必备要素
```
【基本信息】歌名｜歌手｜时长｜曲风/BPM｜画幅｜MV 类型
【歌曲解读】歌曲的情绪曲线 + 核心意象（一句话）
【视觉概念（Big Idea）】一句话：这支 MV 的"想法"（例：把一段失去的爱情演成一场倒着发生的婚礼）
【视觉母题】1–3 个反复出现的画面/道具/动作
【色彩与质感】主色调、光线、镜头质感，随段落的变化
【叙事线/情绪线】按歌曲段落对应（见下表）
【人物与场景】角色 ≤ 3；场景 ≤ 5（AI 生成时更少）
【记忆点画面】副歌/高潮处的"代表性镜头"
```
- **段落对应表**（必须有）：
  `歌曲段落｜时间｜歌词/情绪｜画面内容｜镜头节奏｜色彩/光线`

### 1.4 创意方向
- **不要 1:1 翻译歌词**（唱"下雨"就拍下雨 = 平庸）。找歌词之下的**情绪与潜台词**，用意象表达，或与歌词形成**对位/反差**（欢快的歌配沉重的画面，反而更有力）。
- **用结构呼应音乐结构**：副歌的画面应比主歌更满、更亮、更大（或刻意更空）；桥段要有视觉上的"破局"或"静止"。
- 副歌的核心画面应**重复出现并递进**，形成视觉上的"hook"。
- 前奏 5 秒内要有**抓眼的第一个画面**。

### 1.5 禁忌
- 画面与音乐节奏脱节（剪辑点不在拍点/乐句上）。
- 叙事过满，副歌里还在交代剧情。
- 无意义的炫技镜头堆砌。

## 二、剧本规则（MV 分镜脚本）

### 2.1 格式：按时间码的分镜脚本
```
镜号｜时间码（mm:ss–mm:ss）｜歌曲段落｜对应歌词（原文）｜画面（景别/运动/场景/角色）｜剪辑节奏｜色彩光线｜备注
```
- **时间码连续，总和 = 歌曲总时长**。
- **歌词栏只引用用户提供的歌词原句，且逐句对位**；用户没给歌词，则该栏写"（器乐/无歌词）"或写情绪标签，不得杜撰歌词。
- 镜头时长：慢歌 平均 3–6 秒/镜；中速 2–4 秒/镜；快歌/副歌 1–3 秒/镜；允许在情绪点使用 8–15 秒长镜头。
- 镜头数参考：3 分 30 秒的 MV 约 50–90 个镜头（视曲风而定）。

### 2.2 写作要求
1. **剪辑点对拍**：标注关键节拍（鼓点/重音/转调处）与画面切换点的对应。
2. 每个歌曲段落的画面要有**明确的功能**：主歌=建立与铺垫；预副歌=蓄力；副歌=释放；间奏=变奏/转折；桥段=转折/内省；尾声=余韵/回扣。
3. 叙事型 MV：剧情要能在**不看歌词**的情况下也看懂，歌词仅作情感加深。
4. 表演型 MV：写出**表演场景的空间设计、灯光、走位**，避免全程同一机位的呆板演唱。
5. 视觉母题至少出现 3 次，且含义递进；结尾回扣开头的画面。
6. 如用 AI 生成：控制单镜头动作复杂度、人物数量，保持角色形象一致（附角色定妆卡）。

### 2.3 交付前检查
- [ ] 时间码覆盖完整歌曲，无缺口、无超出
- [ ] 每句歌词都有对应画面或明确标注无画面
- [ ] 副歌视觉强度高于主歌，有清晰的记忆点镜头
- [ ] 视觉母题 ≥ 3 次出现，结尾回扣
- [ ] 附**时长校验表**：`段落 | 歌曲时间 | 镜头数 | 合计时长`
