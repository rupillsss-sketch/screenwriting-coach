# 05 广告 规范

> 先遵守《00_通用规则》，本文件为广告类的专属规则。

## 0 类别定位与默认值
- 为品牌/产品传递一个核心信息，**在极短时间内让人记住、感受并行动**。创意必须服务于品牌目标，而不是只追求好看。
- **默认时长**：用户未指定 → 30 秒。常见 15 / 30 / 60 / 90 秒。
- **默认画幅**：横屏 16:9（用户指定竖屏 9:16 时，构图与字幕区域按竖屏处理）。
- 核心追求：**一个洞察 + 一个创意概念 + 一个记忆点**（只讲一件事）。

## 一、故事大纲（创意概念）规则

### 1.1 必须具备（缺失则追问，最多 3 个问题；用户不给就用 [品牌名]/[产品] 占位并声明假设）
1. 品牌 / 产品 / 核心卖点（只选 1 个主卖点）
2. 目标人群
3. 投放场景（电视/电梯/信息流/社交媒体）
4. 想要的情绪（温暖/幽默/燃/高级/反转）

### 1.2 大纲结构：创意简报式
```
【基本信息】品牌｜产品｜时长｜画幅｜投放场景
【消费者洞察】一句话：目标人群真实存在、但没被说出的心理/矛盾
【核心主张】一句话：品牌想让人记住什么（Slogan 候选 3 个）
【创意概念】一句话：用什么"想法"把洞察和主张连起来（Big Idea）
【叙事方式】反转型 / 对比型 / 情感小故事型 / 演示型 / 世界观型 / 幽默梗型（选 1）
【时间预算表】见下
【详细大纲】按时间块写清画面与情绪
【记忆点】最想让观众带走的 1 个画面 / 1 句话 / 1 个声音
【品牌露出计划】产品/Logo 出现的时间点与时长
```

### 1.3 时间预算模板（按总时长缩放）
| 时长 | 钩子 | 冲突/洞察 | 产品解法 | 品牌升华/落版 |
|---|---|---|---|---|
| 15s | 0–2s | 2–8s | 8–13s | 13–15s |
| 30s | 0–3s | 3–12s | 12–25s | 25–30s |
| 60s | 0–5s | 5–25s | 25–50s | 50–60s |
| 90s | 0–8s | 8–40s | 40–75s | 75–90s |

- **品牌/产品露出**：不得晚于总时长 **60%** 处首次出现（反转型例外，但落版必须清晰）；Logo 落版 ≥ 2 秒（15 秒版 ≥ 1.5 秒）。

### 1.4 创意方向
- 先找**洞察**，再找创意，不要先有画面再硬套产品。
- 提升创意的方法：**把卖点"演"出来**而不是"说"出来；用**夸张/反差/拟人/反转**让信息具象；一个好的广告能"把产品拿走创意仍成立"的是弱创意——要让**产品是创意的必要条件**。
- 必须有**一个可复述的瞬间**（别人看完能一句话讲给朋友）。

### 1.5 禁忌与合规
- 一支广告只讲 **1 个核心信息**。多卖点堆叠=零记忆。
- **禁止虚假和绝对化用语**：如"最""第一""顶级""100%有效""根治"等（符合中国《广告法》），医疗、保健、金融、教育类广告需额外谨慎：不得承诺疗效/收益。
- 不得贬低竞品、不得使用真实名人形象（除非用户声明已授权）。
- 未成年人、烟酒、药品、金融类按行业规范处理，必要时提示用户做合规审核。

## 二、剧本规则

### 2.1 格式：分镜脚本表（广告行业标准形式）
```
镜号｜时间码｜画面（景别/动作/场景）｜旁白/台词｜音乐音效｜字幕/特效
```
- 总时长 = 目标时长，**时间码连续无空隙**，最后一格结束于总时长。
- 单镜时长：15 秒版 1–3 秒/镜；30 秒版 1.5–4 秒/镜；60 秒及以上 2–6 秒/镜。镜头数参考：30 秒约 8–15 镜。

### 2.2 文案量控制
- 旁白/台词字数：按 **3–3.5 字/秒** 计算，并留出画面呼吸空间：
  - 15 秒 ≤ 45 字；30 秒 ≤ 90 字；60 秒 ≤ 180 字（建议再留 20% 空白）。
- Slogan 单独成行，时长 ≥ 2 秒，字数 ≤ 12 字。

### 2.3 写作要求
1. **前 3 秒必须有钩子**（视觉冲击/疑问/反常识），因为信息流广告第 3 秒就可能被划走。
2. 叙事只有一条线，**不允许分支**。
3. 产品出现要**自然且有功能意义**（解决了问题、制造了反转），而非生硬摆放。
4. 声音设计要写：音乐风格/情绪走向、关键音效、静默点。
5. 落版：Logo + Slogan + （必要时）行动号召（行动号召最多 1 个）。
6. 如果大纲里有"记忆点"，剧本必须有一个镜头/一句话专门承载它。

### 2.4 交付与检查
- [ ] 时间码连续，总时长精确
- [ ] 字数不超限
- [ ] 首次产品露出时间符合大纲
- [ ] 只有一个核心信息
- [ ] 无违规用语
- 附 **时长校验表**：`时间块 | 计划时长 | 实际镜头合计 | 字数`
