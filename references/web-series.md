# 03 网络剧 规范

> 先遵守《00_通用规则》，本文件为网络剧类的专属规则。

## 0 类别定位与默认值
- 为网络平台（长视频/流媒体）制作的剧集，节奏比传统电视剧更快，**类型更鲜明、梗更密、情绪更直接**。
- **默认体量**：用户未指定 → 12 集 × 20 分钟。常见 6–24 集，单集 10–45 分钟。
- **默认画幅**：16:9 横屏（用户指定竖屏时按竖屏构图思路写）。
- 核心追求：**强类型 + 强人设 + 快节奏 + 每集必有"追更理由"**。

## 一、故事大纲规则

### 1.1 结构（按总集数 N 分配）
| 段落 | 占比 | 任务 |
|---|---|---|
| 黄金开局 | 第 1–2 集（或前 15%） | **第 1 集前 3 分钟内**抛出核心冲突/悬念；第 1 集结尾必须有大钩子 |
| 上升 | ~15%–50% | 类型看点集中兑现；每 2–3 集一个小高潮 |
| 反转点 | 约 50% 处 | 颠覆认知的转折（身份、真相、关系） |
| 加速 | ~50%–85% | 节奏更快、赌注更大 |
| 终局 | 最后 ~15% | 终极对决 + 情感收束 + 彩蛋/余味 |

### 1.2 大纲必备要素
1. **高概念设定**：能用一句话说清、一听就想看（"如果……会怎样"）。
2. **强人设**：每个主要角色有清晰的"标签 + 反差"（如：冷面法医，却会给尸体盖被子）。
3. **类型承诺清单**：该类型观众最想看的 5 个场面，并标明将出现在第几集。
4. **追更钩子表**：每集结尾的钩子类型（悬念/反转/抉择/情感爆点/神秘新人物），避免重复。
5. **分集大纲**：沿用「02 电视剧」的分集格式，但**每集聚焦 1 条主冲突**，副线精简（≤1 条）。
6. **情绪节拍**：每集标注"爽点/笑点/泪点/怕点"，保证单集内至少 2 个。

### 1.3 创意方向
- **类型混搭有新意**（悬疑+职场、喜剧+科幻等），但必须有统一的情绪基调。
- 用"**规则**"带动剧情：设定一个清晰的规则/代价，每集在规则内玩出新花样。
- 贴近当下观众的情绪点（职场、关系、成长、社会话题）但避免说教。

### 1.4 禁忌
- 前 3 集没有任何强冲突。
- 每集结构雷同、套路化严重（连续 3 集同一种钩子）。
- 为反转而反转，破坏人物逻辑。

## 二、剧本规则

### 2.1 单集结构（以 20 分钟为例）
- **前 1–2 分钟：钩子**（冲突/悬念直接开场）
- 第一段（~6 分钟）建立本集问题 → 第二段（~8 分钟）升级与反转 → 第三段（~4 分钟）高潮与收束 → **最后 1 分钟：集尾钩子**
- **体量**：1 分钟 ≈ 300–400 字（节奏快，对白密度偏高）；20 分钟 ≈ 6000–8000 字；场景约 10–18 个。
- 单集时长按用户设定同比缩放（10 分钟集：钩子约 30 秒、2 个转折、末尾 30 秒钩子）。

### 2.2 写作要求
1. 对白**短、快、有梗**，每段对白都应带来信息或情绪变化。
2. 每个场景 ≤ 2 分钟；场景切换要有"目的性"。
3. 人设必须**在前 5 分钟内通过行动展示**，不要靠旁白介绍。
4. 每集至少 1 个"可被剪成短视频传播的名场面"（金句/反转/情绪爆点）。
5. 保持大纲中的钩子表与情绪节拍落地；跨集伏笔登记表与 02 电视剧一致。
6. 交付时每集附 前情摘要 + 人物状态 + 时长校验。

### 2.3 交付前检查
- [ ] 集数/单集时长与大纲一致（±10%）
- [ ] 前 3 分钟有强钩子，集尾有追更钩子
- [ ] 本集情绪节拍（爽/笑/泪/怕）≥ 2 个
