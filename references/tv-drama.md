# 02 电视剧 规范

> 先遵守《00_通用规则》，本文件为电视剧类的专属规则。

## 0 类别定位与默认值
- 长篇连续叙事，靠"**人物成长 + 多线交织 + 集集有钩**"留住观众。
- **默认体量**：用户未指定 → 24 集 × 45 分钟（一季）。常见 8–12 集（精品短季）、24–40 集（传统剧）。
- **默认画幅**：16:9 横屏。
- 核心追求：**全季弧线 + 每集小完整 + 集尾钩子**。

## 一、故事大纲规则

### 1.1 大纲分三层（必须都有）
1. **全剧总纲**：Logline、主题命题、世界观、全季（或全剧）主线、终局走向。
2. **人物小传 + 人物关系图**：主要角色（5–8 人）+ 关系变化路径（谁与谁，从何到何）。
3. **分集大纲**：每集一条。

### 1.2 全季结构（按总集数 N 按比例分配）
| 段落 | 集数占比 | 任务 |
|---|---|---|
| 开局 | 前 ~15% | 人物亮相、世界规则、主线启动；**第 1 集即抛出全季核心悬念/问题** |
| 发展 | ~15%–45% | 副线展开，关系建立，小高潮 1 |
| **中点转折** | 约 50% 处 | 全局性反转/真相揭示，让后半季的"游戏规则"改变 |
| 恶化 | ~55%–80% | 矛盾激化、人物关系破裂、低谷 |
| 决战与收束 | 最后 ~20% | 终极对决、主线与副线收束、人物弧光完成 |

> 每 4–6 集设置一次"阶段性高潮"（小闭环 + 新问题）。

### 1.3 分集大纲格式（每集必备）
```
第X集｜标题｜预估时长 XX 分钟
- 本集目标：（主角本集想要什么）
- A线（主线）：……
- B线（副线）：……  C线（可选）：……
- 关键转折：……
- 情绪曲线：开场→高点→结尾
- 集尾钩子：（悬念/反转/抉择）
- 伏笔登记：埋下/回收了什么
```

### 1.4 必备要素
- **主线 + 至少 2 条副线**，副线必须与主线主题呼应（而不是随便凑）。
- **集的类型**：标注每集是"推进集 / 情感集 / 悬念集 / 高潮集"，避免连续多集同一功能。
- **人物弧光表**：每个主要角色在 起点 / 中点 / 终点 的状态。
- **伏笔回收表**：跨集伏笔必须标注"第几集埋→第几集收"。
- **类型承诺**：该剧类型的 3 个核心看点要均匀分布于各集。

### 1.5 创意方向
- "**可持续的设定引擎**"：设定要能产生一整季的故事，而不是只够 3 集（例如"每集一个案件 + 贯穿的个人谜团"）。
- 让**人物关系成为主线**：长剧的黏性来自关系，而不是事件。
- 反派/对立面要在**中点**升级为更深层的对手。

### 1.5.1 禁忌
- 注水集：任何一集若删掉不影响主线与人物，则重写或删除。
- 中段（40–70%）剧情停滞、人物原地打转。
- 结局草率：最后 3 集必须回收所有主线悬念。

## 二、剧本规则

### 2.1 单集结构
- 单集 45 分钟 ≈ **冷开场（2–4 分钟）+ 4–5 幕 + 集尾钩子**，每幕结尾有小转折。
- **体量**：1 分钟 ≈ 300–380 字；45 分钟 ≈ 1.4–1.7 万字；场景约 20–35 个。
- 集数、单集时长必须与大纲完全一致（如 24 集 × 45 分钟）。

### 2.2 分集交付与连续性
- 默认**逐集生成**（或用户指定一批若干集）。每集开头附：
  - **前情提要**（3–5 行）
  - **人物状态表**（各主要角色当前情绪/关系/已知信息）
  - **伏笔登记表**（已埋 / 待收）
- 严格遵守分集大纲：A/B/C 线、关键转折、集尾钩子不得缺失。

### 2.3 写作要求
1. **冷开场**要快速建立本集问题，不得铺垫过长。
2. A/B 线要**交叉剪接**，B 线在关键处与 A 线产生呼应或反差。
3. 每一幕结束有"小转折"；每集中点有"反转或升级"。
4. **信息管理**：观众知道什么、角色知道什么，写作时标注清楚（戏剧反讽的来源）。
5. 对白需保持人物声音一致，**跨集不得出现性格漂移**。
6. 集尾钩子必须是"让人必须点下一集"的东西（新信息/抉择/危机），不是单纯切黑。

### 2.4 交付前检查
- [ ] 本集时长（字数）符合 ±10%
- [ ] 分集大纲每个要点已落地
- [ ] 与前后集的伏笔、人物状态连续
- [ ] 集尾钩子到位
